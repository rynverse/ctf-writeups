# CTF Write-ups
Welcome to my CTF's write-up repository! Here you can find the various guides and scripts I make for the CTF (Capture the Flag) challenges I participate in.

## Writeups
The format for this repository is `[year-of-ctf]/[ctf-event]/[write-up]`.

Each write-up will consist of
```
write-up
-> [images]
-> ctf-event.md (The write up)
-> ctf-even-script.sh (If applicable)
```
Each write-up will contain a guide, script and accompanying images, as well as a takeaway from each CTF and what they demonstrate. 

For easy navigation, I have also included a table with links to each write-up as well as:

- Name of Challenge
- Link to write-up
- A difficulty score (/10) [1 being lowest difficulty| 10 being highest difficulty]
- Appropriate tags
